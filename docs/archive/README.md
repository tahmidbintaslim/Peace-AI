# Archived first-draft notes

These files were written alongside the first version of the app in
November 2025 and moved here from the repository root in October 2026.
They are kept unchanged for history.

They are out of date and several of their claims are not true of the code:

- They describe the app as "production-ready" (`COMPLETION_SUMMARY.md`,
  `PROJECT_SUMMARY.md`). It is a prototype.
- They count "50+ verses from 25+ Surahs". The dataset in
  `lib/services/islamic_knowledge_service.dart` holds 46 verses from 29
  surahs and 20 hadiths.
- They list desktop targets and API documentation that the repository does
  not contain.

For how the app works, how to run it and its current status, read the
[main README](../../README.md) and the code.
